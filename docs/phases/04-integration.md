# Phase 4 前后端联调

**状态**：已完成（2026-09-24）

**目标**：把前后端接到一起跑通全链路，处理大文件与异常路径，并准备好发布。

## 任务清单

1. 打通真实后端（去掉 mock 分支、开发期 CORS）。
2. 全链路联调：配置 → 上传 sample.xlsx → 第一轮 → 筛选 → 第二轮 → 导出。
3. 大文件与并发体验：1 万行上传、3 万条候选分页。
4. 异常联调：无效 Key、配额耗尽、无 AOI、列不识别、空文件、名称超 80 字符。
5. 文档与发布准备：README 三步跑通、MIT 许可证、隐私声明、打 v0.1.0 标签。

## 验收标准

- 前置条件：Phase 3 的字段核对差异为零。
- 全链路无需改代码即可跑通，导出的 CSV 与两份 GeoJSON 可被 Excel 与 GIS 打开。
- 异常路径都有明确提示且不崩溃（AOI 无权限时提示提工单）。
- 干净克隆目录按 README 三步能跑起来。

## 验收记录

**完成时间**：2026-09-24

**实现了什么**

- 开发期 CORS：仅当 `DEV=1` 时允许 Vite 开发服务器来源，生产同源不需要。
- 超长名称护栏：超过 80 字符的名称不发起请求，直接记为 `name_too_long`（高德 keywords 上限就是 80）。
- 空文件与空数据：无表头返回 400，只有表头没有数据行返回 422。
- 样本生成：`scripts/gen_sample_csv.py` 可生成任意行数的压测名单。
- 发布材料：完整 README、MIT 许可证、隐私声明、`.env.example`。
